# CreatorOS

Este projeto foi desenvolvido como parte do processo seletivo da empresa YouShop, com o objetivo de propor uma solução inovadora para a creator economy por meio do uso de inteligência artificial e centralização de processos.

**Importante:** este projeto é um **protótipo conceitual**, criado para demonstrar a proposta, a experiência do usuário e a visão do produto. Algumas funcionalidades utilizam dados simulados e não representam uma solução pronta para produção.

## Tecnologias Utilizadas

- React com Vite

## Como Executar

### Pré-requisitos

- Node.js
- npm

### 1 - Clonar o repositório

```bash
git clone https://github.com/KristianKirschner/desafio-youshop.git
cd desafio-youshop
```

### 2 - Instalar as dependências

```bash
npm install
```

### 3 - Executar a aplicação

```bash
npm run dev
```

A aplicação estará disponível em:

```txt
http://localhost:5173
```


## Funcionalidades

- Dashboard com visão geral do negócio
- Gestão de conteúdo e calendário editorial
- Gestão de campanhas e lançamentos
- Analytics com métricas e indicadores
- Controle de afiliados e comissões
- Módulo financeiro
- Automações e fluxos inteligentes
- Centralização de integrações
- Assistente de IA para insights e recomendações
